# Gesteq | Consultoria em Gestão Empresarial

Bem-vindo ao repositório do projeto **Gesteq**. Este é o código-fonte da landing page desenvolvida para a Gesteq, uma empresa especializada em consultoria estratégica, padronização de processos e desenvolvimento de líderes e equipes.

## 📌 Sobre o Projeto

Este projeto consiste em uma página web responsiva, otimizada e de alta performance, estruturada com HTML5, CSS3 e JavaScript (Vanilla). O layout e a experiência do usuário foram projetados para transmitir profissionalismo e clareza sobre os serviços oferecidos pela consultoria.

**Nota importante:** Este site foi desenvolvido durante a minha passagem como desenvolvedor em uma agência de marketing. O projeto faz parte do meu portfólio profissional, demonstrando minhas habilidades em desenvolvimento web front-end, criação de interfaces dinâmicas, animações e otimização para SEO e performance.

## 🚀 Tecnologias Utilizadas

- **HTML5:** Estruturação semântica e SEO.
- **CSS3:** Estilização avançada, animações modulares e responsividade adaptativa.
- **JavaScript (Vanilla):** Lógica para componentes interativos, menus dinâmicos e carrosséis automatizados, sem uso de frameworks pesados.
- **Lenis:** Biblioteca para _smooth scrolling_, garantindo uma navegação premium.

## ⚙️ Funcionalidades em Destaque

- **Navegação Dinâmica:** Menu responsivo e pop-ups de navegação estruturados em JS.
- **Carrossel Infinito:** Exibição contínua e suave de logotipos de clientes, divididos por segmentos (Indústria, Varejo, Serviços, etc.).
- **Contadores Animados:** Exibição de estatísticas e marcos da empresa com animação numérica baseada em rolagem.
- **Timeline de Metodologia:** Componente visual para demonstrar os pilares e o método de atuação da Gesteq.
- **SEO Técnico:** Implementação de meta tags avançadas, Open Graph, e JSON-LD (`LocalBusiness`) para maximização do ranqueamento.

## 💻 Como Visualizar

O projeto foi construído utilizando tecnologias nativas da web (Vanilla). Para rodar o projeto localmente:

1. Faça o clone ou o download do projeto.
2. Abra o arquivo `index.html` no seu navegador de preferência.
3. Não há necessidade de instalar pacotes via `npm` ou configurações complexas de build.
